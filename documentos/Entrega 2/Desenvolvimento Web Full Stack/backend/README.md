# Projeto Backend – Instituto Alma

## 🚀 Visão Geral
Este repositório contém o backend para o projeto do Instituto Alma, implementado com Node.js.  
O serviço está hospedado na plataforma Render e pode ser acessado através do link:  
[https://projeto5-v8ko.onrender.com](https://projeto5-v8ko.onrender.com)

> Nota: No momento, se houver algum erro de acesso, verifique as variáveis de ambiente e logs no Render.
